# Como escrever suas notas em Markdown

O KeepInMind usa Markdown para formatar suas notas. Não precisa decorar nada — a maior parte é bem intuitiva, e este guia cobre tudo que é suportado.

## Títulos

Use `#` no começo da linha para criar títulos. Quanto mais `#`, menor o título.

```
# Título grande
## Título médio
### Título pequeno
```

## Negrito e itálico

```
**Isto fica em negrito**
*Isto fica em itálico*
***Isto fica em negrito e itálico***
```

## Quebra de linha

Aperte Enter uma vez para quebrar a linha. Para começar um parágrafo novo, deixe uma linha em branco entre os textos.

```
Esta linha
quebra aqui embaixo.

Este é um parágrafo separado.
```

## Listas

Listas simples, com `-`:

```
- Primeiro item
- Segundo item
- Terceiro item
```

Listas numeradas:

```
1. Primeiro passo
2. Segundo passo
3. Terceiro passo
```

Sub-itens: indente com dois espaços.

```
- Item principal
  - Sub-item
```

## Listas de tarefas

Marque coisas como feitas ou pendentes:

```
- [x] Tarefa concluída
- [ ] Tarefa pendente
```

## Links

```
[Texto do link](https://exemplo.com)
```

## Código

Para uma palavra ou trecho curto, use um `crase` de cada lado:

```
Use o comando `npm install` para instalar.
```

Para um bloco de código maior, use três crases antes e depois:

````
```
function exemplo() {
  console.log("código em bloco")
}
```
````

## Citação

Use `>` no começo da linha para destacar um trecho:

```
> Isto aparece como uma citação.
```

## Tabelas

```
| Coluna A | Coluna B |
|----------|----------|
| Valor 1  | Valor 2  |
| Valor 3  | Valor 4  |
```

## Texto riscado

```
~~Isto aparece riscado~~
```

## Dica rápida

Se uma nota ficar muito grande na tela principal, ela é cortada — clique nela para ver o conteúdo completo.
